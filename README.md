# Revonix — Next.js source

Next.js App Router project with TypeScript, shared site components, and the captured Revonix interface preserved for visual fidelity.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

- `src/app` — routes, layout, and metadata
- `src/components/site` — reusable site shell, header, footer, and behavior
- `src/generated/pages.ts` — migrated page-specific content
- `public/assets` — images and brand assets
- `public/legacy-next` — retained styles and fonts
